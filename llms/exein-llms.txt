# Exein

> Exein is a Physical AI / embedded and IoT cybersecurity company (Italy). It secures connected devices, firmware, and Linux/RTOS embedded systems through on-device runtime security and AI-powered firmware analysis, mapping findings to standards such as the EU Cyber Resilience Act, ETSI EN 303-645, and IEC 62443. Exein does not publish a hosted public API; its developer surface is open-source security tooling on GitHub (Pulsar, Kepler).

## Products
- [Exein Runtime](https://www.exein.io/platform/exein-runtime): Real-time, on-device threat detection for resource-constrained Physical AI, Linux, and RTOS devices.
- [Exein Analyzer](https://www.exein.io/platform/exein-analyzer): AI-powered firmware security — binary analysis + SBOM ingestion, vulnerability prioritization, and CRA/compliance mapping.

## Open Source Tooling
- [Pulsar](https://github.com/exein-io/pulsar): Modular, eBPF-powered runtime security tool/agent for IoT and Linux (docs at https://pulsar.sh/).
- [Kepler](https://github.com/exein-io/kepler): NIST-based CVE lookup store and REST API, powered by Rust (self-hosted, default http://localhost:8000).
- [meta-exein](https://github.com/exein-io/meta-exein): Exein layer for Yocto.

## Applications
